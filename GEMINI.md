# Catalyst Hackathon Project Guidelines

These guidelines apply to all development and agent turns within this repository:

1. **AI Judge Optimization**: Every feature and commit should target top marks across the 6 Hack2Skill/Google for Developers AI evaluation criteria:
   - Idea uniqueness & creativity
   - Relevance to the given problem statement
   - Modern, aesthetic, and responsive UI
   - Professional repository structure and documentation
   - Code cleanliness, typing, modularity, and error handling
   - Solution scalability (serverless, caching, containerization)

2. **Jury Testing Assurance**:
   - Provide pre-loaded demo/mock data so the live deployed prototype works immediately out-of-the-box without requiring complex onboarding.
   - Use toast notifications and loading skeletons to give immediate feedback.

3. **Deliverables Focus**:
   - Keep GitHub repository clean and ready for public push via `gh repo create`.
   - Maintain Vercel one-command production deployment readiness (`vercel --prod`).
   - Keep the LinkedIn submission write-up aligned with MnM & Catalyst format.
